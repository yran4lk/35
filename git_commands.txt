git init - создает новый пустой репозиторий Git в текущей папке.
git clone - скачивает удаленный репозиторий со всей его историей на ваш компьютер.
git status - показывает текущее состояние репозитория: измененные, новые или удаленные файлы.
git add - добавляет файлы в индекс (подготавливает их к сохранению).
git commit -m "текст" - создает коммит - фиксирует сохраненные изменения с поясняющим сообщением.
git log - выводит список всех прошлых коммитов в хронологическом порядке.
git branch - показывает список веток в проекте или создает новую при указании имени.
git checkout - переключает вас на другую ветку.
git pull - скачивает свежие изменения из удаленного репозитория и объединяет их с вашими.
git push - отправляет ваши локальные коммиты на удаленный сервер (например, GitHub)
